# Contributing

Issues and pull requests are welcome, in English or Turkish.

```bash
npm ci
npm start        # demo, UI5 1.108
npm test         # needs a local Chrome; runs on UI5 1.108 and 1.154
npm run build
```

- Baseline is UI5 1.108: do not use newer APIs.
- `*.gen.d.ts` files are generated by `npm run typecheck` and not committed; `src/icons.ts` is generated by `npm run icons`.
- Every control must work with the keyboard, in dark mode, in a narrow container and right-to-left.
- A control does not depend on `sap.m` and takes its look only from the `--kor-*` variables.
- Add a QUnit test for every bug fix.
